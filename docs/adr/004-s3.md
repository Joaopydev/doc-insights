# ADR 004 — S3

## Context

Raw documents, extracted text artifacts, summaries, risk details, and retrieval content must be stored durably and accessed by Lambda functions.

## Decision

Use Amazon S3 for raw document upload storage and processed artifact persistence.

## Alternatives Considered

- EFS: provides file-system semantics but is more expensive and unnecessary for object-centric storage.
- DynamoDB binary fields: not cost-effective or scalable for large document payloads.

## Consequences

- Durable, low-cost object storage with native Lambda and IAM integration.
- Necessitates lifecycle management, secure bucket policies, and encryption at rest.
- Supports storing both raw payloads and structured output artifacts separately.
